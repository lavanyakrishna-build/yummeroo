# Yummeroo

Saved recipes, searchable, with cook-with-what-you-have matching.

The site is served by GitHub Pages from the `gh-pages` branch. Recipes come from Muse's
"Yummeroo Recipes" spreadsheet; a scheduled sync updates `index.html` every 6 hours when
new recipes appear. Pantry, checklist ticks and notes are saved in each visitor's own browser.
